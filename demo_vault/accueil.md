# Bienvenue dans Knit v0.3.0

Knit est votre environnement de documentation, de wiki et de gestion de projet **Local-First**, **Peer-to-Peer** et en **Markdown Pur**.

> [!NOTE]
> Zéro base de données cachée ni format propriétaire : vos notes restent lisibles avec n'importe quel éditeur de texte (Obsidian, VS Code, micro, Vim).

---

## 🧭 Découverte des Vues Pilotées par le Document (Doc-Driven Views)

Explorez les modules interactifs complets inclus dans ce coffre :

- [[live-preview.md|Démonstration Live Preview]] : Rendu Obsidian, 7 statuts de tâches, priorités `!p1`-`!p3`, blocs de code, Mermaid réactif à `--knit-hue`.

- [[liens-navigation.md|Navigation & Rétroliens]] : WikiLinks `[[...]]`, ancres internes `[[#...]]`, aperçu au survol (Hover Preview) et rétroliens.
- [[document-long.md|Test de Performance Document Long]] : Banc d'essai sur document étendu pour valider la réactivité et la fluidité 60 FPS.
- [[wiki/architecture.md|Architecture Technique]] & [[wiki/piliers.md|Les 9 Piliers de Knit]].

## ⚡ Raccourcis Clavier Essentiels

| Action | Raccourci Clavier | Description |
| :--- | :---: | :--- |
| **Sauter à un fichier** | <kbd>Ctrl+O</kbd> | Quick Switcher instantané avec recherche floue |
| **Palette de commandes** | <kbd>Ctrl+P</kbd> | Liste de toutes les actions applicatives |
| **Bascule Source / Live Preview** | <kbd>Ctrl+E</kbd> | Permute entre Markdown brut et vue visuelle |
| **Scinder l'espace de travail** | <kbd>Ctrl+\</kbd> | Split View avec groupes d'onglets indépendants |
| **Mode Zen Immersif** | <kbd>Ctrl+Shift+F</kbd> | Masque les barres pour une concentration totale |
| **Note Quotidienne** | <kbd>Ctrl+Shift+J</kbd> | Ouvre ou génère le journal du jour |
| **Packager Contexte IA** | <kbd>Ctrl+Shift+C</kbd> | Copie la note propre pour les agents IA |
